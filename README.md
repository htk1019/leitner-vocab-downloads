# 단어의 서랍 · 설치 파일

가족용 무료 영한 단어장입니다.

- 웹·모바일: https://leitner-vocab.onrender.com
- Windows: [설치 파일](https://github.com/htk1019/leitner-vocab-downloads/releases/latest/download/Leitner-Vocab-Setup.exe)

한글 뜻·품사·사전에 있는 예문을 사전에서 자동 입력합니다. Claude 계정이나 유료 API 키 없이 사용할 수 있습니다. 첫 방문 후 홈 화면에 추가하면 모바일 앱으로 사용할 수 있습니다. 단어와 학습 내용은 각 기기에 저장됩니다.

이 저장소는 설치 파일과 공개 사전 데이터의 출처 안내만 제공합니다. 개인 단어장과 로그인 인증 정보는 포함하지 않습니다.

사전 데이터: 한국어 위키낱말사전(https://ko.wiktionary.org/), Kaikki.org(https://kaikki.org/dictionary/rawdata.html), Open Multilingual Wordnet(https://github.com/omwn/omw-data), Princeton WordNet(https://wordnet.princeton.edu/). 결합 사전 CC BY-SA 4.0(https://creativecommons.org/licenses/by-sa/4.0/). 온라인 보완: FreeDictionaryAPI.com(https://freedictionaryapi.com/), MyMemory(https://mymemory.translated.net/). [사전 출처와 원문 이용 조건](https://leitner-vocab.onrender.com/dictionary/LICENSE.txt).

Windows 설치 파일은 개인 인증서로 서명하지 않았습니다. Windows에서 게시자를 확인할 수 없다는 안내가 나올 수 있습니다.

## v0.2.1 자동 입력 개선

`lots of`, `a lot of`, `plenty of` 등 생활 표현 47개에 뜻·학습용 미국식 발음기호·영한 예문을 포함합니다. 사전 검색 시 빈 항목을 채우고 직접 입력은 유지합니다. 누락된 일반 단어 발음·예문은 [FreeDictionaryAPI.com](https://freedictionaryapi.com/)의 Wiktionary(CC BY-SA 4.0) 자료로 무료 보완합니다. 사전 출처와 라이선스는 릴리스의 LICENSE.txt에 있습니다.

## v0.2.2 합성어 보강

생활·학교·교통·음식·자연 등 합성어 298개의 뜻과 영한 예문을 보강했습니다. `fire house`/`firehouse`, `fire truck`/`firetruck` 같은 확인된 표기 변형을 연결합니다. [FreeDictionaryAPI.com](https://freedictionaryapi.com/)과 English Wiktionary(CC BY-SA 4.0)의 발음 자료를 이용하며, 전체 이용 조건과 직접 작성한 데이터의 출처는 릴리스의 LICENSE.txt에 있습니다. 기존 앱은 새 설치 파일을 실행해 업데이트하세요. 설정 하단에서 버전 0.2.2를 확인할 수 있습니다.
